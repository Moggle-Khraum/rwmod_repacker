About the Tool

RWMod Repacker was created to help mod authors protect their own work. Using this tool is optional — it is entirely up to each author whether they want to pack their mods or not. Since some mods also reuse or borrow code from other creators, using the repacker will always depend on the author's own preference.

DISCLAIMER

This tool does NOT guarantee 100% protection!

The tool/software still has it's flaws and limitations due to the limited knowledge of the author. The obfuscation process is called 'dummying' — a mixture of dummy structuring, encapsulation, and junk injection which creates a layer of protection to discourage casual theft.
